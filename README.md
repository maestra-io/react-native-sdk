# Maestra SDK for React Native

The Maestra SDK allows developers to integrate mobile push notifications, in-app messages, and client events into your React Native projects.

## Getting Started

These instructions will help you integrate the Maestra SDK into your React Native app.

### Installation

Coming soon.

### Initialization

Initialize the Maestra SDK in your React Native app. You can find the necessary code snippet and explanations [here](https://developers.maestra.io/docs/2-initializing-sdk).

### Operations

Learn how to send events to Maestra. Different operations and their usage are detailed [here](https://developers.maestra.io/docs/8-integrating-actions-in-your-app).

### Push Notifications

Maestra SDK aids in handling push notifications. It offers configurations and usage instructions, found in the SDK documentation [Android(FCM)](https://developers.maestra.io/docs/31-android-sending-push-notifications-via-firebase), [IOS](https://developers.maestra.io/docs/41-ios-sending-push-notifications) and [IOS(Rich)](https://developers.maestra.io/docs/312-sending-rich-push-notifications-using-appdelegate-copy).
